`go-toolbox` 是一个面向日常开发和文件处理场景的 Go 小工具集合项目。



## go小工具
### find-and-copy

```powershell
cd go-toolbox

# 打包到path
go build -o E:\dev\bin\find-and-copy.exe .\cmd\find-and-copy

# 使用
find-and-copy.exe -ext .mp3 -src "D:\AsukaFiles\AsuMusic2.0\新音乐\临时1_全部"

```
